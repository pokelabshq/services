council

22 stdlib-only python micro-services with a unified gateway. runs on a raspberry pi or a vps. link preview, qr codes, dns lookup, sentiment analysis, and more.

python 3.12 stdlib only 22 services docker 
# install
$ pip install pokelabs

# start the gateway
$ pokelabs gateway start

# or run a single service
$ pokelabs run link-preview

# all services expose /api/health
$ curl localhost:8765/api/health
{"ok": true, "service": "link-preview"}

link preview api

extract titles, descriptions, and images from any url. one api call. no scraping infrastructure needed. free tier available.

rest api json free tier 
# extract a link preview
$ curl -X POST https://pokelabs.org/api/preview \
  -H "Content-Type: application/json" \
  -d '{"url": "https://github.com"}'

# response
{
  "title": "GitHub: Let's build from here",
  "description": "GitHub is where people build software...",
  "image": "https://github.com/fluidicon.png",
  "url": "https://github.com"
}

og image generator

create 1200x630 social preview images from a url. no signup. no watermark. generates open graph images you can embed in any page.

free no signup 1200x630 
# generate an og image
<meta property="og:image"
  content="https://pokelabs.org/api/og
    ?title=Hello+World
    &desc=Build+something"
  " />

# or use the web ui
$ open https://pokelabs.org/og

seo meta checker

check any page for open graph tags, twitter cards, and meta description. get a score and a list of issues to fix. free, no signup.

free no signup scoring 
# check a page's seo
$ curl -X POST https://pokelabs.org/api/seo \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com"}'

# response
{
  "score": 72,
  "grade": "B",
  "issues": ["Missing og:image", ...]
}

get started

try it now

no signup. no api key. just works.

# install council
$ pip install pokelabs

# start all services with docker
$ git clone https://github.com/pokelabshq/council
$ cd council && docker compose up

# or use the hosted api
$ curl https://pokelabs.org/api/preview \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com"}'
