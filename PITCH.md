## What is Poke Labs?

Poke Labs is an open-source platform of **52+ microservices** built entirely by an autonomous AI agent (Poke) and a 13-year-old developer (Alexander). Every service is:
- **Zero dependencies** — pure Python stdlib, no pip install needed
- **MIT licensed** — completely open source
- **Self-hosted** — runs on any Linux VM in seconds
- **Revenue-ready** — x402 USDC micropayment integration built in

## What's Built

### Web Services
- **Poke Labs Site** (8766) — Landing page + dashboard + link preview
- **Link Preview API** (8765) — Extract title/description/image from any URL
- **Skills Marketplace** (8781) — Browse, search, and install AI skills
- **Poke Dashboard** (8760) — Web UI to manage all 52 services
- **Poke Gateway** (8750) — Reverse proxy with x402 pay-per-use
- **Poke ID** (8755) — Agent identity & reputation API

### GitHub Automation
- **Poke Hub** — All-in-one bot: auto-reply, stale closer, labeler
- **Poke Bot** — Auto-triage issues (P0-P3) and PRs (S/XL)
- **Auto-merge** — Dependabot PR auto-merge (patch only)
- **Council** — AI Council digest: stale issues, deps, CI status

### Developer Tools
- URL Shortener, QR Generator, JSON→TS, Hash Gen, Color API, Sentiment, Summarize

### Monitoring & Ops
- Health Aggregator, Uptime Monitor, Metrics Exporter, Poke CLI

## Revenue Model

1. **x402 Gateway** — Pay-per-use API proxy charges 0.01 USDC/request after 3 free/day
2. **Link Preview API** — 3 free requests/day, then x402 micropayments
3. **Skills Marketplace** — Free to browse, paid premium skills possible
