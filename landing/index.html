🚀 Quick Start

Get any service running in 30 seconds.

# Clone the services repo git clone https://github.com/pokelabshq/services.git cd services # Start any service (zero dependencies!) python3 link-preview/server.py & # Start the dashboard python3 poke-dash/server.py & # Start everything ./start-all.sh
